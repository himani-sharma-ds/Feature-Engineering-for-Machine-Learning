# 🚀 Feature Engineering for Machine Learning

A collection of **Feature Engineering** techniques implemented using **Python**, **Pandas**, and **Scikit-learn**. This repository demonstrates how to preprocess data and transform categorical features into machine-learning-ready formats.

---

## 📖 Project Overview

Feature Engineering is one of the most important steps in the Machine Learning workflow. The quality of features directly impacts the performance of a model.

This repository contains practical implementations of commonly used feature engineering techniques with Jupyter Notebooks and sample datasets.

## 🎯 Feature Engineering Techniques

### ✅ Missing Value Imputation

* Identify missing values
* Analyze null values
* Handle missing data using appropriate techniques
* Prepare clean datasets for Machine Learning

### ✅ Label Encoding

* Convert categorical values into numerical labels
* Use Scikit-learn's `LabelEncoder`

### ✅ One-Hot Encoding

* Transform categorical variables into binary columns
* Avoid introducing ordinal relationships

### ✅ Ordinal Encoding

* Encode ordered categorical variables while preserving their ranking
